## 🏗️ INVENTORY MANAGEMENT ARCHITECTURE

To optimize token efficiency and prevent memory drift, skills are structured in two layers:
1. **Master Inventories (Compressed Layer):** Capability rules are compressed into a single inventory file per domain category.
2. **Heavy Skills (Folder Layer):** Complex skills requiring accompanying executable scripts, assets, or tools maintain their folder structures.
